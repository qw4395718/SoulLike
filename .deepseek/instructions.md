## 注释规范

1. 使用 `// ` 单行注释的方式注释函数和变量，禁止使用 `/** */` 进行单行注释
2. 所有的函数的传入参数要以 `In` 开头，传出参数以 `Out` 开头
3. 代码块的注释标签规范，用 `/******/` 框包围：

   - 实现某 `IWeaponAccessory_IF` 接口的函数 → `IWeaponAccessory_IF 接口实现`
   - 由父类继承实现的函数 → `继承实现`
   - `Public:` 区域的函数 → `外部调用`
   - `Private: / Protected:` 区域的函数 → `内部调用`
   - `Public:` 区域的变量 → `外部访问`
   - `Private: / Protected:` 区域的变量 → `内部访问`
