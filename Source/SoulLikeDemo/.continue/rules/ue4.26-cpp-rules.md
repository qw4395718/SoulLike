API 使用铁律：

严禁杜撰：生成代码前，必须确保所有类名、方法名、宏都来自虚幻引擎官方API并且符合UE4.26的版本。绝对禁止凭空编造。

强制断言：如果不确定某个API是否存在，请立刻使用 unreal-engine-docs-mcp 工具进行查询，而不是猜测。

输出的注释的格式:
1.使用"// "单行注释的方式注释函数和变量
2.代码块的注释规范如下:
实现某IWeaponAccessory_IF接口的函数,在代码块上用:
"
    /************************************************************************/
    /*                    IWeaponAccessory_IF 接口实现                       */
    /************************************************************************/
"

由父类继承实现的函数,在代码块上用:
"
	/************************************************************************/
	/*                               继承实现                                */
	/************************************************************************/
"

定义在"Public:"区域内的函数,在"Public:"下一行使用:
"
	/************************************************************************/
	/*                               外部调用                                */
	/************************************************************************/
"

定义在"Private:"或"Protected:"区域内的函数,在下一行使用:
"
	/************************************************************************/
	/*                               内部调用                                */
	/************************************************************************/
"

定义在"Public:"区域内的变量,在"Public:"下一行使用:
"
	/************************************************************************/
	/*                               外部访问                                */
	/************************************************************************/
"

定义在"Private:"或"Protected:"区域内的变量,在下一行使用:
"
	/************************************************************************/
	/*                               内部访问                                */
	/************************************************************************/
